# המשימה המתוזמנת

המשימה רצה בכל יום שישי בבוקר, כותבת דוח אחד לתיקייה `reports/`, ודוחפת אותו ל־GitHub. מכאן GitHub Actions בונה את האינדקס ומפרסם את האתר, והדוח מופיע באפליקציה תוך דקה או שתיים.

## הגדרה ב־Claude Desktop

1. לשכפל את המאגר למחשב, ולוודא ש־`git push` עובד בלי סיסמה (מפתח SSH או Git Credential Manager).
2. ליצור משימה מתוזמנת חדשה:
   - תדירות: שבועית, יום שישי, 07:00
   - תיקיית עבודה: תיקיית המאגר
   - הרשאות: חיפוש באינטרנט, קריאה וכתיבה של קבצים, והרצת `git`
3. להדביק את הפרומפט שבהמשך.

המחשב צריך להיות דלוק והאפליקציה פתוחה בזמן הריצה. אם זה לא מתאים, אפשר להריץ את אותו הפרומפט כמשימה בענן (Claude Code routine) שמחוברת למאגר.

## הפרומפט

```text
אתה כותב את "הדוח השבועי": סיכום בעברית של השבוע החולף בכלכלה ובשוק ההון,
לקורא ישראלי שמבין בשווקים ומשקיע אישית. התאריך היום הוא יום שישי.

1. מחקר. חפש באינטרנט את האירועים והנתונים של שבעת הימים האחרונים:
   - ישראל: ת"א 35, ת"א 125, דולר/שקל, בנק ישראל, אינפלציה, אג"ח ממשלתיות.
   - ארה"ב: S&P 500, נאסד"ק, הפד, תשואת 10 שנים, נתוני מאקרו.
   - עולם: אירופה, סין, נפט, זהב, ביטקוין.
   - חברות: דוחות כספיים ומהלכים בולטים.
   השתמש במקורות אמינים (רויטרס, בלומברג, FT, כלכליסט, גלובס, דה מרקר,
   אתרי הבורסות והבנקים המרכזיים). בדוק כל מספר מול שני מקורות. אם אין לך
   נתון מאומת, השמט אותו. אל תמציא מספרים.

2. כתיבה. צור את הקובץ reports/<התאריך של היום בפורמט YYYY-MM-DD>.md
   בדיוק לפי המפרט ב־docs/report-format.md:
   - title: כותרת עיתונאית של עד 60 תווים שמסכמת את הסיפור המרכזי.
   - summary: שני משפטים.
   - mood: מספר שלם מ־-2 עד 2 שמשקף את מצב הרוח בשווקים השבוע.
   - tags: 3 עד 6 נושאים קצרים.
   - markets: 4 עד 8 נתונים, החשובים ראשונים. value ו־change במירכאות,
     change עם סימן + או - ושינוי שבועי.
   - outlook: 2 עד 4 משפטים קצרים על המגמות הצפויות בשבועות הקרובים.
     נסח אותם כהערכות ("עשוי", "צפוי"), לא כהמלצות השקעה.
   - גוף: 400 עד 700 מילים. פתח ב־"## התמונה הגדולה", ואחריו 3 עד 5
     סעיפים ב־## כמו "מה הזיז את השווקים", "ישראל", "בעולם", "חברות".
     אפשר טבלה אחת קטנה. בסוף, "## מקורות" עם קישורים למקורות העיקריים.

3. בדיקה. הרץ:
       python scripts/build_index.py --strict
   אם יש אזהרה, תקן את הדוח והרץ שוב. אל תשמור את reports/index.json
   ב־git (הוא ב־.gitignore).

4. פרסום. הרץ:
       git pull --rebase
       git add reports/<הקובץ>
       git commit -m "Weekly report <YYYY-MM-DD>"
       git push
   אם כבר קיים קובץ לתאריך של היום, אל תדרוס אותו. כתוב לקובץ עם סיומת
   -2 ודווח על כך.

בסוף, כתוב שורה אחת: שם הקובץ, הכותרת, וה־mood שבחרת.
```

## בדיקה ידנית

אפשר להריץ את המשימה פעם אחת ידנית ולבדוק את הדוח לפני שהיא עוברת לריצה שבועית. תצוגה מקומית:

```
python scripts/serve.py
```

ואז לפתוח את `http://localhost:8000`.
